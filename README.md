# Home Master — Android-приложение (Android 5.0+)
Клиент для сервера из `repair_service/server`. Языки: RU, UK, EN, PT (папка `locales`).

## Получить HomeMaster.apk
**A. В облаке GitHub (без установки чего-либо):** загрузите содержимое этой папки (вместе с `.github` и `camerax_provider`)
в репозиторий → вкладка **Actions → Build APK → Run workflow** → через 20–40 минут скачайте артефакт `HomeMaster-apk`.
**B. Локально (Ubuntu/WSL):** `./build_local.sh` → `HomeMaster.apk`.
Установка: скопируйте APK на телефон, разрешите установку из неизвестных источников.

## Регистрация заказчика
Логин и пароль · имя и фамилия · телефон · компания · сайт · адрес · положение на карте (GPS устройства **или** выбор вручную
перекрестием на карте) · паспортные данные · скан/фото документа (камера **или** JPEG/PDF из памяти) · согласие на обработку данных.
Сервер хранит паспортные данные **зашифрованными** (Fernet), показывает их только суперпользователю, каждый просмотр пишет в журнал.
Тип файла проверяется по содержимому (подделанное расширение не пройдёт).

## Камера (максимальное качество)
`camera.py`: Android CameraX через Camera4Kivy — режим `optimize='quality'`, запрос разрешения 4000×3000, автофокус по касанию,
зум щипком, вспышка. Снимок сохраняется JPEG в приватную папку приложения (не попадает в галерею).
Для сборки нужны `camera4kivy`, `gestures4kivy`, папка `camerax_provider` и `p4a.hook` — всё уже прописано в `buildozer.spec`.

## Карты (maps.py)
| Провайдер | Как включить |
|---|---|
| `google` (по умолчанию) | официальный **Google Map Tiles API**: получите ключ в Google Cloud, включите «Map Tiles API», ограничьте ключ этим API и задайте `GOOGLE_MAPS_KEY` на сервере. Без ключа приложение само переключится на OSM |
| `osm` | для разработки |
| `custom` | свой онлайн-сервер тайлов: `CUSTOM_TILE_URL=https://tiles.example.com/{z}/{x}/{y}.png` |
| `offline` | тайлы на телефоне: `python tools/prefetch_tiles.py ...` → папка `offline_tiles` в каталоге приложения |

Провайдер задаёт сервер (`MAP_PROVIDER`), а пользователь может переопределить его в «Настройки → Провайдер карт».
**Свой провайдер:** добавьте функцию в `maps.py` и запись в словарь `PROVIDERS`.
Важно: тайлы Google нельзя скачивать пачкой для офлайна и использовать вне Google-карт — это нарушает условия. Для офлайна берите свой/лицензированный источник.

## Проверка на ПК
`pip install -r requirements-desktop.txt && python main.py` (камера на ПК заменяется выбором файла).
