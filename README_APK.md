# Как получить HomeMaster.apk

Android 5.0 и выше (API 21). Сборка идёт в облаке GitHub — на вашем ПК ничего устанавливать не нужно.

## Способ 1 — GitHub (рекомендую), ~15 минут вашей работы + 30–60 минут ожидания
1. Зарегистрируйтесь на https://github.com (бесплатно) и нажмите **New repository**. Имя любое (например, `homemaster`),
   тип **Private**, нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**.
3. Распакуйте архив и **перетащите в окно браузера ВСЁ содержимое папки `home_master`**, включая папки
   `.github`, `camerax_provider`, `locales`, `tools` (перетаскивайте именно папки и файлы, а не саму `home_master`).
   Нажмите **Commit changes**.
   Проверьте, что в репозитории появились `buildozer.spec`, `main.py` и папка `.github/workflows/build-apk.yml`.
4. Вкладка **Actions** → слева **Build APK** → справа **Run workflow** → зелёная кнопка **Run workflow**.
   (Если Actions просит разрешения — нажмите «I understand my workflows, go ahead and enable them».)
5. Подождите 30–60 минут (первая сборка скачивает Android SDK/NDK, следующие быстрее). Откройте завершённый запуск
   (зелёная галочка) → внизу раздел **Artifacts** → скачайте **HomeMaster-apk** (ZIP, внутри `HomeMaster.apk`).

**Если запуск завершился красным крестом:** откройте его → внизу Artifacts → **build-log** → пришлите мне этот файл
(или последние ~40 строк лога) — я найду причину и исправлю.

## Способ 2 — на своём компьютере
* Ubuntu 22.04 или Windows с WSL2 (Ubuntu): `./build_local.sh` → получится `HomeMaster.apk` (нужно ~10 ГБ места).
* Через Docker: `docker run --rm -v "$(pwd)":/home/user/hostcwd kivy/buildozer android debug` → APK в папке `bin/`.

## Установка на телефон
1. Скопируйте `HomeMaster.apk` на телефон (кабель, Telegram «Избранное», Google Диск).
2. Откройте файл → разрешите «Установку из неизвестных источников» для этого приложения → **Установить**.
   (Это отладочная сборка, подписана тестовым ключом — для проверки и тестирования она подходит.)
3. При первом запуске разрешите доступ к геоданным и камере.
4. В окне входа укажите **адрес вашего сервера** (например, `https://service.example.com`).
   Телефон должен видеть сервер: для доступа из интернета нужен HTTPS-адрес (Cloudflare Tunnel, Nginx Proxy Manager, Caddy).
   В домашней Wi-Fi-сети можно использовать `http://IP-ПК:8000`, но тогда в `buildozer.spec` потребуется разрешить HTTP
   (Android 9+ блокирует незашифрованный трафик) — напишите, и я добавлю.

## Если приложение вылетает или что-то не работает
* Ошибки показываются на экране окном с текстом — сделайте скриншот и пришлите мне.
* Камера (CameraX) и выбор файлов проверялись только в песочнице без телефона — самые вероятные места для доработок.
